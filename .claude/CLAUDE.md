# Public repository

This repository is public. Anything committed here can be read by anyone.

- Commit messages, pull request titles and descriptions, and code comments
  state what changed and the technical reason only.
- No business, pricing or market reasoning, and no customer or usage counts.
- No "owner's decision" markers, dated decision references or decision codes.
- No links to private repositories and no local paths (for example `/Users/...`).
- Legal drafts are prepared privately and arrive here only once approved.

A local, untracked `CLAUDE.md` at the repository root may carry further
development context; it is ignored by git and never committed.
