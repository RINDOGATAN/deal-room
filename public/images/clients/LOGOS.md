# Customer logos: sources

One file per logo. The page shows every file muted (CSS `brightness(0) invert(1)` at 60 % opacity,
the same light silhouette as before) and, on devices with a pointer that can hover, removes the
filter on hover so the logo shows in its own colours. Five logos are in full colour; five stay one
colour (white ink) because their colour version is not readable on the dark page and the source
offers no colour version for dark grounds (see the last column).

Every SVG was rebuilt from the source paths only (no scripts, no external references, no metadata,
no styles, no embedded images) and optimised with svgo 3.3.2. Retrieved 11 October 2026.
